# ФВМиБ КНАУ — прототип сайта

Сайт факультета ветеринарной медицины и биотехнологии КНАУ им. К.И. Скрябина. Статический прототип для согласования, не официальный сайт факультета.

React, TypeScript, Vite, React Router (`HashRouter`). Интерфейс на русском языке. Шрифты Inter и Manrope поставляются локально через Fontsource; сетевые сервисы, аналитика и серверная часть не используются.

## Запуск

Node.js 24 и npm:

```sh
npm ci
npm run dev
```

## Проверки

```sh
npm run typecheck
npm run build
npx playwright install chromium
npm run preview -- --port 4173
npm run test:smoke
```

Для проверки GitHub Pages задайте `VITE_BASE_PATH=/knau-fvmb/` и при сборке, и при запуске preview. В PowerShell: `$env:VITE_BASE_PATH = '/knau-fvmb/'`. По умолчанию smoke-тест использует `http://127.0.0.1:4173/knau-fvmb/`; для сборки в корне задайте `SMOKE_URL=http://127.0.0.1:4173/`.

Тест проверяет девять маршрутов на 390/768/1024/1440 px, отсутствие горизонтального переполнения, полный заголовок министерства, ссылки AVN, меню с клавиатуры, управление фокусом, обновление вложенного маршрута и шесть проверок axe. Отчёт и скриншоты сохраняются в игнорируемую папку `artifacts/`.

## Структура

- `src/content/site.ts` — типизированные данные, навигация и явно обозначенные проекты текстов.
- `src/components/` — общая шапка, меню, подвал и повторно используемые секции.
- `src/pages/` — главная, о факультете, миссия, деканат, профиль и заготовки.
- `src/styles/` — токены Stitch и адаптивные стили.
- `docs/design-source.md` — источники экранов, соответствие маршрутам и ограничения материалов.
- `.github/workflows/deploy.yml` — сборка и публикация GitHub Pages из `main`.

## Содержание и изображения

Макеты Stitch содержат противоречащие друг другу сведения о кафедрах, биографии, статистику, новости и личные контакты без подтверждения. Они не публикуются как официальные факты. Проекты миссии и тематических текстов явно отмечены; места для фотографий обозначены нейтральными рамками. Формы не имитируют отправку обращения и не собирают личные данные.

## GitHub Pages

В настройках репозитория выберите **Settings → Pages → Source: GitHub Actions**. После push в `main` workflow выполняет `npm ci`, сборку с базой `/knau-fvmb/` и публикацию `dist`. Фактический адрес публикуется в окружении `github-pages` после успешного выполнения Actions.

Переходы используют `/#/about/mission`, поэтому обновление вложенных страниц не требует серверных правил маршрутизации. Официальный домен КНАУ не изменяется.
