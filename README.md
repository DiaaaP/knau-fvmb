# ФВМ КНАУ — сайт факультета

Факультет ветеринарной медицины КНАУ им. К.И. Скрябина. Статический сайт для согласования.

## Текущая версия

- Главная, «О факультете», «Миссия», «Деканат», профиль сотрудника и «Индустриальный совет».
- «О нас» объединяет миссию и деканат в выпадающем меню.
- Образовательный портал ведёт на https://avn.knau.kg в новой вкладке.
- Пустые разделы для абитуриентов, студентов, кафедр и контактов не показываются.
- По последнему запросу восстановлены Manrope/Inter и стиль первой версии. Полная строка министерства выровнена по центру. Большой нижний подвал удалён.
- В миссии удалены блоки фундаментальной/прикладной науки и биотехнологии/генетики.
- На странице Индустриального совета опубликованы предоставленные пользователем цель, пять предлагаемых категорий участников и восемь задач. Персональный состав не утверждается и не выдумывается.

React, TypeScript, Vite, React Router (`HashRouter`). Manrope и Inter поставляются локально через Fontsource. Серверная часть, аналитика и сбор личных данных не используются.

## Запуск

Node.js 24 и npm:

```sh
npm ci
npm run dev
```

## Проверки

```sh
npm run typecheck
npm run build
npx playwright install chromium
npm run preview -- --port 4173
npm run test:smoke
```

Для GitHub Pages задайте `VITE_BASE_PATH=/knau-fvmb/` и при сборке, и при запуске preview. В PowerShell: `$env:VITE_BASE_PATH = '/knau-fvmb/'`.

По умолчанию smoke-тест использует `http://127.0.0.1:4173/knau-fvmb/`. Для сборки в корне задайте `SMOKE_URL=http://127.0.0.1:4173/`.

Тест проверяет шесть маршрутов на 390/768/1024/1440 px, полную и центрированную строку министерства, шрифт Manrope, отсутствие старого названия/подвала/удалённых блоков, меню, фокус, вложенный маршрут, ссылки AVN, состав новой страницы и восемь аудитов axe. Отчёт и скриншоты сохраняются в игнорируемую папку `artifacts/`.

## Содержание

Источники — материалы пользователя, проект Stitch и [предоставленный чат](https://chatgpt.com/share/6af8c9a8-1e00-83ed-8195-2058ecf8ee27). Роль и квалификация заместителя декана сверены с оригинальными скриншотами. Личные мобильные номера и персональная почта сотрудников не перепубликуются. Миссия остаётся обозначенным проектом. В Индустриальном совете указаны предлагаемые категории участников, без заявлений об их назначении.

Подробности: `docs/design-source.md`. Проверки: `docs/verification.md`.

## Публикация

Workflow `.github/workflows/deploy.yml` публикует `dist` после push в `main`.

Адрес сайта: https://diaaap.github.io/knau-fvmb/

Страница совета: https://diaaap.github.io/knau-fvmb/#/industrial-council

Вложенные страницы используют HashRouter и открываются при обновлении без серверных правил. Официальный домен КНАУ не изменяется.
