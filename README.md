# Факультет ветеринарной медицины КНАУ

Сайт факультета ветеринарной медицины КНАУ им. К.И. Скрябина для согласования.

## Текущая версия

- Главная, о факультете, миссия, деканат и профили руководства.
- Документы, абитуриентам с обращением ректора, студентам.
- Каталог пяти кафедр, страница кафедры инфекционных и инвазионных болезней животных, профиль заведующей и галерея сотрудников.
- Индустриальный совет: предоставленные пользователем цель, пять категорий предлагаемого состава и восемь задач.
- Внешний образовательный портал: https://avn.knau.kg.
- 14 исходных изображений перенесены из предоставленных скриншотов. Посторонний интерфейс телефона, браузера, чата и уведомления не публикуется.
- Manrope/Inter, бело-синее оформление и центрированная строка министерства сохранены; большой нижний подвал отсутствует.

React, TypeScript, Vite, React Router (`HashRouter`). Изображения и шрифты хранятся локально. Серверной части, аналитики и сбора данных нет.

## Запуск

Node.js 24 и npm:

```sh
npm ci
npm run dev
```

## Проверки

```sh
npm run build
npx playwright install chromium
npm run preview -- --port 4173
npm run test:smoke
```

Для проверки GitHub Pages задайте `VITE_BASE_PATH=/knau-fvmb/` при сборке и запуске preview. В PowerShell: `$env:VITE_BASE_PATH = '/knau-fvmb/'`.

По умолчанию smoke-тест проверяет `http://127.0.0.1:4173/knau-fvmb/`. Для сборки в корне задайте `SMOKE_URL=http://127.0.0.1:4173/`.

Проверяются 18 маршрутов на 390/768/1024/1440 px, меню и фокус, вложенные ссылки, AVN, галерея, раскрываемые секции, социальные ссылки, отключение анимаций при уменьшении движения и 12 аудитов axe. Сборка включает строгую проверку TypeScript. Скриншоты и отчёт сохраняются в игнорируемой `artifacts/`.

Адреса WhatsApp, Instagram и Facebook находятся в `src/content/social.ts` и предоставлены пользователем. Иконки — Bootstrap Icons (MIT); лицензия включена в `public/licenses/bootstrap-icons.txt`. Короткие анимации и сине-белые кнопки описаны в `src/styles/motion.css`.

## Источники и ограничения

По последнему запросу данные и вкладки перенесены из 16 скриншотов исходного сайта. Сам `fv.knau.kg` возвращает HTTP 403 в доступной среде, поэтому полная выгрузка не получена.

Переписаны только читаемые фрагменты миссии, точные названия кафедр, показанные имена/должности/квалификации и контакты. Остальным портретам не присвоены выдуманные имена. Неизвестные документы, обращение ректора и подробные тексты четырёх кафедр пока не заполнены.

- `docs/source-import.md` — перечень источников, области изображений, перенесённое и недостающее.
- `docs/verification.md` — проверки.
- `docs/design-source.md` — история проекта и ссылка на исходный чат.
