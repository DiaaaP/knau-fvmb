# ФВМ КНАУ — прототип сайта

Факультет ветеринарной медицины КНАУ им. К.И. Скрябина. Демонстрационная версия для согласования, не официальный сайт.

## Текущая версия

- Главная, «О факультете», «Миссия», «Деканат» и профиль сотрудника.
- «О нас» объединяет миссию и деканат в выпадающем меню.
- Образовательный портал ведёт на https://avn.knau.kg в новой вкладке.
- Пустые разделы для абитуриентов, студентов, кафедр и контактов удалены. Контактная информация находится в подвале и на странице деканата.
- Сдержанная университетская вёрстка: системный шрифт Georgia для заголовков, локальный Inter для основного текста, белый и тёмно-синий, тонкие разделители. Нет сеток рекламных карточек, пустых новостей и декоративных фотозаглушек.

React, TypeScript, Vite, React Router (`HashRouter`). Серверная часть, аналитика и сбор личных данных не используются.

## Запуск

Node.js 24 и npm:

```sh
npm ci
npm run dev
```

## Проверки

```sh
npm run typecheck
npm run build
npx playwright install chromium
npm run preview -- --port 4173
npm run test:smoke
```

Для GitHub Pages задайте `VITE_BASE_PATH=/knau-fvmb/` и при сборке, и при запуске preview. В PowerShell: `$env:VITE_BASE_PATH = '/knau-fvmb/'`.

По умолчанию smoke-тест использует `http://127.0.0.1:4173/knau-fvmb/`. Для сборки в корне задайте `SMOKE_URL=http://127.0.0.1:4173/`.

Тест проверяет пять маршрутов на 390/768/1024/1440 px, полную строку министерства, отсутствие старого названия и ссылок на удалённые разделы, меню, управление фокусом, обновление вложенного маршрута, ссылки AVN и шесть аудитов axe. Отчёт и скриншоты сохраняются в игнорируемую папку `artifacts/`.

## Исходные материалы

Источники — проект Stitch и [чат, предоставленный пользователем](https://chatgpt.com/share/6af8c9a8-1e00-83ed-8195-2058ecf8ee27). Роль и квалификация заместителя декана проверены по оригинальным скриншотам, а не по сгенерированной биографии Stitch. Личные мобильные номера и персональная почта сотрудников не перепубликуются. Миссия явно обозначена как проект. Фотографии не заменяются сгенерированными портретами.

Подробности: `docs/design-source.md`. Результаты проверок: `docs/verification.md`.

## Публикация

Workflow `.github/workflows/deploy.yml` публикует `dist` после push в `main`. В Settings → Pages выбран источник GitHub Actions.

Подтверждённый адрес: https://diaaap.github.io/knau-fvmb/

Вложенные страницы используют `/#/about/mission` и открываются при обновлении без серверных правил маршрутизации. Официальный домен КНАУ не изменяется.
