# Проверка текущей версии

Production-сборка с `VITE_BASE_PATH=/knau-fvmb/`.

- `npm run build` проходит, включая строгую проверку TypeScript.
- `npm run test:smoke`: 24 проверки страниц — шесть маршрутов × 390/768/1024/1440 px.
- Заголовки действительно отображаются шрифтом Manrope.
- Полная строка министерства видна и центрирована на всех страницах.
- Старое название с «биотехнологии», большие нижние блоки и удалённые направления миссии отсутствуют.
- Удалённые пустые направления не связаны ссылками.
- Горизонтального переполнения нет.
- Все шесть маршрутов открываются через реальные ссылки; профиль — из каталога деканата.
- Оба меню проверены с клавиатуры, включая закрытие по Escape и возврат фокуса.
- Мобильное меню удерживает фокус внутри диалога и раскрывает подразделы.
- Вложенный маршрут сохраняется после обновления.
- У AVN проверены точный URL, новая вкладка и `noopener noreferrer`.
- На странице совета пять групп предлагаемого состава и восемь задач, цель соответствует предоставленному тексту. Разговорное обращение к пользователю отсутствует.
- Восемь аудитов axe: главная, миссия, профиль и совет на 390/1440 px. Обнаруживаемых нарушений WCAG A/AA нет.
- Ошибок JavaScript и загрузки ресурсов нет.

Скриншоты шести страниц на 390/1440 px находятся локально в `artifacts/v3-*.png`. Главная просмотрена на обеих ширинах и сверена со скриншотами пользователя: возвращены исходные шрифты, шапка и оформление hero, строка министерства центрирована, нижнего синего подвала нет. Новая страница совета просмотрена на мобильной ширине.

Аудит axe не заменяет полный ручной аудит доступности.
