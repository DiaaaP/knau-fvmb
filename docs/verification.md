# Проверка текущей версии

Production-сборка с `VITE_BASE_PATH=/knau-fvmb/`.

- `npm run build` проходит, включая строгую проверку TypeScript.
- `npm run test:smoke`: 20 проверок страниц — пять маршрутов × 390/768/1024/1440 px.
- Название больше не содержит «и биотехнологии»; проверяется также отсутствие старого сокращения в видимом тексте.
- Ссылок на удалённые пустые разделы нет.
- Полная строка министерства видна на всех страницах и ширинах.
- Горизонтального переполнения нет.
- Все направления открываются через реальные ссылки; профиль — из каталога деканата.
- Выпадающее меню работает с клавиатуры; Escape закрывает его с возвратом фокуса.
- Мобильное меню удерживает фокус внутри диалога, раскрывает подразделы, закрывается при переходе и по Escape.
- Вложенный маршрут сохраняется после обновления.
- У AVN проверены точный URL, новая вкладка и `noopener noreferrer`.
- Шесть аудитов axe: главная, миссия и профиль на 390/1440 px. Обнаруживаемых нарушений WCAG A/AA нет.
- Ошибок JavaScript и загрузки ресурсов нет.

Скриншоты всех пяти страниц на 390/1440 px сохранены локально в `artifacts/v2-*.png`. Главная просмотрена на обеих ширинах; проверены шапка, типографика, переносы, ссылки, подвал и отсутствие прежних сеток карточек/фотозаглушек.

Аудит axe не заменяет полный ручной аудит доступности.
