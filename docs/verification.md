# Проверка текущей версии

Production-сборка с `VITE_BASE_PATH=/knau-fvmb/`.

- `npm run build` проходит, включая строгую проверку TypeScript.
- `npm run test:smoke`: 72 проверки — 18 маршрутов × 390/768/1024/1440 px.
- Полная строка министерства видна и центрирована; заголовки используют Manrope.
- В интерфейсе отсутствуют прежнее название с «биотехнологии», удалённый большой подвал и прежние сгенерированные научные блоки.
- Восстановленные вкладки и пять кафедр открываются через ссылки с соответствующих родительских страниц.
- Переполнения по горизонтали нет; ошибок JavaScript и загрузки ресурсов нет.
- Оба меню проверены с клавиатуры, включая Escape, удержание/возврат фокуса и переход на вложенную страницу после обновления.
- Мобильное подменю кафедр содержит пять исходных направлений и открывает страницу кафедры.
- Галерея оригинальных фотографий открывает просмотр и закрывается по Escape.
- Раскрываемые секции кафедры работают.
- Ссылки AVN имеют точный адрес, новую вкладку и `noopener noreferrer`.
- Индустриальный совет сохраняет пять предлагаемых категорий участников и восемь задач.
- Миссия факультета содержит читаемый абзац источника вместо ранее сгенерированного проекта.
- 12 аудитов axe: главная, миссия, профиль, совет, кафедра и абитуриенты на 390/1440 px. Обнаруживаемых нарушений WCAG A/AA нет.

Скриншоты 18 страниц на 390/1440 px находятся локально в `artifacts/v4-*.png`. Визуально просмотрены главная на мобильной ширине, деканат на настольной и кафедра на мобильной. Все 14 выделенных изображений отдельно проверены на контактном листе: посторонний интерфейс телефона и уведомления не публикуются.

Ограничения источника перечислены в `docs/source-import.md`. Аудит axe не заменяет полный ручной аудит доступности.
