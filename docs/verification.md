# Проверка прототипа

Проверена production-сборка с `VITE_BASE_PATH=/knau-fvmb/`.

- `npm run build` — проходит, включает строгую проверку TypeScript.
- `npm run typecheck` — проходит.
- `npm run test:smoke` — 36 проверок страниц (девять маршрутов × 390/768/1024/1440 px).
- Полный текст министерства виден на всех проверенных страницах и ширинах; горизонтального переполнения нет.
- Все девять направлений открываются через реальные ссылки. Профиль проверен по вложенному маршруту, обновление страницы сохраняет маршрут.
- Выпадающее меню работает с клавиатуры, Escape закрывает его и возвращает фокус.
- Мобильное меню: раскрытие подразделов, удержание фокуса внутри диалога, Escape, закрытие при переходе, возврат фокуса и восстановление прокрутки.
- У ссылок AVN проверены точный URL, `target="_blank"` и `rel="noopener noreferrer"`.
- Шесть аудитов axe: главная, миссия и профиль на 390/1440 px. Нарушений WCAG A/AA, обнаруживаемых axe, нет. Это не заменяет полный ручной аудит доступности.
- Ошибок JavaScript и сетевых запросов нет.

Скриншоты всех пяти основных страниц сохранены на 390/1440 px локально в `artifacts/`. Главная просмотрена на обеих ширинах и сопоставлена со скриншотом Stitch: сохранены шапка, сетка, типографика, чередование секций и порядок блоков. Фотографии, спорные сведения и фиктивные действия намеренно заменены обозначенными рамками, проектами текстов и рабочей навигацией. Полное попиксельное соответствие не заявляется.

При первой проверке исправлены обход фокуса мобильного меню и недостаточный контраст подписей рамок. Итоговый прогон проходит полностью.
